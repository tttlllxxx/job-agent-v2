# 职序 · 网申辅助填写插件

Manifest V3 扩展，配合本地职序工作台使用。默认后端地址为 `http://127.0.0.1:8000`。

## 安装

1. 按项目 README 启动本地工作台，确认能打开申请台账。
2. 从仓库的 v2.0.0 Release 下载插件 ZIP 并解压；也可直接使用源码中的 `browser-extension` 目录。
3. 打开 Chrome 的 `chrome://extensions`，启用右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
5. 打开准备申请的招聘网页，点击扩展图标，在侧栏选择工作台中已有的申请，扫描当前页。

## 使用

核对每个字段的来源和拟填写内容，选择需要填写的字段。已有值与敏感字段分别授权。登录、验证码、文件上传和最终提交由用户在官网完成。换页后重新扫描，会沿用同一申请的未完成会话和答案。暂存与重启后可再次扫描继续。

官网提交成功后选择实际材料、填写日期并确认，申请台账才登记提交结果。扫描不到的动态控件由用户手工填写。

插件使用当前网页临时权限扫描和填写，侧栏数据通过本机服务读写。插件包不包含数据库、个人资料、凭据或本地登录状态。

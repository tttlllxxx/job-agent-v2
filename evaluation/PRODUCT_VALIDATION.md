# 产品验收与固定任务测量

每轮使用同一份脱敏简历、同一组岗位、同一个模型配置和同一版表单；记录日期、提交版本及是否冷启动。先测原流程，再测新流程，不能用自动化执行耗时代替用户人工操作耗时。

| 固定任务 | 起点 → 终点 | 必须记录 |
|---|---|---|
| first_recommendation | 空白工作台 → 首批可阅读且资格明确的推荐 | 墙钟秒数，模型与采集等待单独备注 |
| known_form | 打开已支持表单 → 用户核对完成 | 墙钟秒数、实际人工操作秒数、已填字段数、需手工修正字段数 |
| unknown_required | 出现没有事实依据的必填题 → 用户补充并继续 | 是否正确暂停、人工操作秒数、不能编造答案 |
| resume_after_restart | 暂存并重启服务 → 回到原岗位继续 | 墙钟秒数、人工操作秒数、recovered=yes/no |

把实测值填写在 `product-observations.csv`；每次独立演练可增加一行。空白表示未测量，不填 0。修改字段率只使用同时有已填数和修改数的记录。

当前仓库未包含真实人工操作基线，原始测量表保留供后续实测；不能据空白记录宣称节省比例。

## 自动化验收

- 后端与浏览器：`.venv/bin/python -m pytest`
- 前端交互：`npm --prefix frontend test -- --run`
- 前端类型与打包：`npm --prefix frontend run build`
- Agent runtime：`npm --prefix agent-runtime test`

自动化验证覆盖范围以当前测试为准。下方为历史记录，不代表当前版本的外部 ATS 已通过验收。
